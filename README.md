## 🚀 Features

- 🌐 Add and manage passwords for websites
- 👁️ Toggle visibility of saved passwords
- ✏️ Edit credentials inline
- 🗑️ Delete entries with confirmation
- 📦 All passwords are stored locally via a custom backend
- ⚡ Toast notifications for feedback
- 🎨 Beautiful and responsive UI using Tailwind CSS
- 🔒 Future-ready for encryption & auth integration
